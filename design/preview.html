The stack

Three products, one platform.

Native desktop app built with Makepad. Chat, images and voice, with local or cloud backends.

  • macOS · Windows · Linux
  • Rust + Makepad UI

OpenAI-compatible HTTP + WebSocket server. Hot-swap models, shared GPU memory.

  • Streaming TTS over WebSocket
